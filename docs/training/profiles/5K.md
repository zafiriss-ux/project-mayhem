# Training Profile: 5K

**Profile ID:** `5K`
**Goal:** Sub-goal 5K race performance via aerobic base + threshold development
**Framework:** OPERATIONAL_MODEL.md (endurance-generic)
**Longevity bias:** Active — safety wins on all conflicts

---

## 1. Athlete Assumptions

This profile is designed for:
- A recreational/competitive runner training for 5K
- Baseline aerobic fitness established (can run 30+ min continuously)
- No current active injury
- Access to HR monitoring (chest strap or optical with ≤3 bpm accuracy)

This profile does **not** assume elite physiology. Conservative ceilings are intentional.

---

## 2. HR Zone Map

| Zone | Name | HR Range | Purpose |
|---|---|---|---|
| Z1 | Recovery | < 130 bpm | Active recovery, warm-up/cool-down |
| Z2 | Aerobic base | 130–145 bpm | Long runs, easy volume |
| Z3 | Tempo / Threshold | 146–153 bpm | Sustained effort; lactate threshold work |
| Z4 | VO2 / Hard | 154–168 bpm | Short intervals, race simulation |
| Z5 | Maximal | > 168 bpm | Sprint finishes only; never prescribed as sustained target |

### 2.1 Threshold HR Ceiling

> **153 bpm — hard ceiling for all threshold and tempo sessions**

This is the Intensity Governor ceiling. Any sustained steady-state effort must not exceed 153 bpm.
If HR climbs above 153 bpm during a prescribed Z3 block: reduce pace until HR returns below ceiling. Do not attempt to "hold pace and wait it out."

### 2.2 Z2 Ceiling

> **145 bpm — Z2 hard ceiling for all easy and long runs**

Easy runs must be genuinely easy. Creep above 145 bpm during a Z2 session = pace is too high.

## 3. Intensity Governor Parameters

| Parameter | Value |
|---|---|
| Threshold HR ceiling | 153 bpm |
| Z2 HR ceiling | 145 bpm |
| Drift soft limit | 4% |
| Drift hard limit | 6% |
| RPE band Z2 | 3–4 / 10 |
| RPE band Z3 (threshold) | 6–7 / 10 |
| RPE band Z4 (VO2) | 8–9 / 10 |

### 3.1 Drift in Practice

During any Z3 (threshold) session block:

- `drift < 4%` → green, continue
- `4% ≤ drift < 6%` → yellow, reduce pace, monitor
- `drift ≥ 6%` → hard stop on intensity block; convert to Z2 cool-down

Example: 20-min threshold run at 148 bpm avg. If at 20 min HR is 156 bpm (5.4% drift), the session continues as Z2. The intensity block is done.

## 4. Gate Thresholds

### 4.1 Negative Signal Thresholds

| Indicator | Baseline Reference | Negative Threshold |
|---|---|---|
| HRV (rMSSD) | 7-day rolling mean | < baseline − 8 ms |
| RHR | 7-day rolling mean | > baseline + 6 bpm |
| Sleep score | Device or subjective | < 60 / 100 (or < 6 hrs quality sleep) |
| Subjective fatigue | Self-report 1–10 | ≥ 7 |

### 4.2 Downgrade Rule (5K instantiation)

> **2 of 4 negatives → session downgrade**

| Gate Color | Condition | Session Action |
|---|---|---|
| GREEN | 0–1 negatives | Execute as prescribed |
| YELLOW | 2 negatives | Downgrade: Z3→Z2, Z4→Z3 max, shorten by 20% |
| RED | 3–4 negatives, or any hard stop | Replace with Z1 (20–30 min easy walk/jog) or full rest |

### 4.3 Hard Stops (5K)

Immediate RED regardless of other signals:

- HRV < baseline − 15 ms (collapse threshold)
- RHR > baseline + 10 bpm
- TSB < −35 AU (acute overload)
- Active injury flag
- In-session drift ≥ 6% during a Z3 block

## 5. VO2 Governor Parameters

| Parameter | Value |
|---|---|
| Min TSB for VO2 sessions | ≥ 0 AU (must be in positive TSB or neutral) |
| Min rest days between VO2 sessions | 2 full days |
| "1 rep in reserve" rule | Mandatory — set ends when next rep would fail |
| Form degradation stop | Any rep where target pace cannot be held within 5 sec/km |

### 5.1 VO2 Session Gate Requirements (5K)

All must be GREEN before a VO2 session is authorized:

- [ ] Gate color = GREEN (no downgrade)
- [ ] TSB ≥ 0
- [ ] HRV ≥ baseline (no suppression)
- [ ] Last session was not VO2 or race-pace (≥2 rest/easy days since)
- [ ] Fueling: carbohydrate-available state confirmed

If any fails → remove VO2 block, replace with Z2.

## 6. Fueling Protocol (5K)

### 6.1 Quality Days (Z3 + Z4 sessions)

- **Pre-session:** Mixed meal 2–3 hrs prior, or light carbohydrate snack 60 min prior
- **During:** For sessions ≤ 60 min: water only acceptable; > 60 min with intensity: 30g carb/hr minimum
- **Post-session:** Within 45 min: 20–30g protein + 40–60g carbohydrate

### 6.2 Easy Days (Z1/Z2)

- Pre-session fueling is flexible
- Fasted Z2 runs ≤ 60 min: acceptable for fat-adaptation stimulus
- Fasted Z2 runs > 60 min: have carbohydrate available but not required to consume

### 6.3 Phase Lock

> **During any training week containing ≥1 Z3 or Z4 session: no fasted or low-carb protocols.**

This applies to the entire week, not just the day before intensity. Chronic carbohydrate restriction blunts adaptation to intensity work.

## 7. Weekly Structure — 5K Phase

### 7.1 Base Phase (Weeks 1–6)

Primary focus: aerobic volume, Z2 development, introduce threshold work.

| Day | Session | Gate Requirement |
|---|---|---|
| Monday | Rest or Z1 mobility | Any |
| Tuesday | Z3 threshold run (20–30 min at target) | GREEN |
| Wednesday | Z2 easy (35–45 min) | GREEN or YELLOW |
| Thursday | Z2 easy (30 min) or rest | Any |
| Friday | Z4 short intervals (4–6 × 800m or 3 × 1200m) | GREEN only |
| Saturday | Z2 long run (45–70 min) | GREEN or YELLOW (shorten if YELLOW) |
| Sunday | Rest or Z1 walk/recovery | Any |

**Weekly volume target:** 35–55 km depending on athlete capacity.
**Intensity sessions per week:** 2 (Tuesday + Friday). Never 3.

### 7.2 Sharpening Phase (Weeks 7–10, pre-race)

Primary focus: race-pace sharpness, maintain Z2 base, taper in final week.

| Day | Session | Gate Requirement |
|---|---|---|
| Monday | Rest | — |
| Tuesday | Race-pace intervals (e.g., 5 × 1km @ 5K goal pace) | GREEN only |
| Wednesday | Z2 easy (30–40 min) | GREEN or YELLOW |
| Thursday | Z1 or rest | Any |
| Friday | Short Z4 or race-pace strides (10 × 200m) | GREEN |
| Saturday | Z2 moderate (40–55 min) | GREEN or YELLOW |
| Sunday | Rest | — |

**Final race week:** Tuesday light strides only, Wednesday Z2 20 min, Thursday–Sunday rest/shakeout.

### 7.3 Structural Constraints

- No intensity on consecutive days. Period.
- If gate forces a rest on a Tuesday or Friday: the session is canceled, not deferred to Wednesday/Saturday.
- Long run never follows a Z4 day.

---

## 8. Success Criteria (5K)

A 5K training block is successful when:

| Criterion | Threshold |
|---|---|
| Gate compliance | ≥ 90% of sessions executed at correct gate-assigned intensity |
| Drift control | Drift < 6% in ≥ 85% of Z3 sessions |
| VO2 session completion | "1 rep in reserve" maintained in all sets |
| Injury-free final 4 weeks | Zero injury flags |
| TSB at race week | +5 to +20 AU (fresh, not detrained) |
| Z2 HR progression | Pace at 140–145 bpm improves ≥ 5% over block |

---

## 9. Failure Patterns (5K-Specific)

| Pattern | How to detect | Consequence |
|---|---|---|
| Threshold creep | Avg Z3 HR consistently 155–158 bpm | Recalibrate HR zones; those were Z4 sessions |
| Long run too hard | Long run avg HR > 148 bpm | Not a long run — aerobic stimulus is wrong |
| VO2 session collapsed | Last 2 reps clearly slower, form gone | Set was 2 reps too long; adjust next week |
| Fueling miss on intensity | Post-session fatigue crash > 4 hrs | Pre-session carb availability issue |
| Override cluster | ≥3 overrides in one week | Mandatory review; next week intensity reduced by 1 session |
| Race-week intensity | Any Z4 session within 5 days of race | Not a sharpener — it's residual fatigue |
